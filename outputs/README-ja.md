# NEON REVENANT v1.2

> **試作中・無保証 / Experimental prototype — AS IS, WITHOUT WARRANTY.** 実機・実カートリッジは未検証です。利用前に[免責事項](../DISCLAIMER.md)と、リポジトリ直下の利用条件・第三者ライセンスを確認してください。

MSX turbo R + V9990向け、512 KiB ASCII8 MegaROMの疑似3Dシューティングです。カートリッジから直接起動し、MSX-DOSは使いません。

v1.2のテーマは「もしMSX3が存在したら」。金属の面、夜の反射、発光する建築を16色で表現することを目指し、背景、自機・敵などのスプライト、パレットを作り直しました。市街地、工業高架道路、中枢トンネルが遠近法に従って手前へ迫る16フレームの前進映像と、左右移動に追従するカメラの慣性は引き継いでいます。ゲームルール、操作、音楽・効果音、素材の配置座標は従来版のままです。

「MSX3」は画づくりのコンセプトです。実行するハードウェアはMSX turbo R + V9990で、現代のPCの3D描画能力や実在するMSX3を意味しません。光や材質感を描き込んだ画像を事前生成し、MSX上で合成する疑似3Dです。

ゲーム本体はMSX上で動くネイティブプログラムです。PC用の3Dエンジンやブラウザーをゲーム実行に使いません。

巨大都市の管制AI「NOX」が夜の交通網を封鎖した。あなたは高速戦闘艇REVENANTを駆り、ネオンの街区、高架道路、黒い中枢塔を突破する。奥から迫る敵を照準で捉え、光の列をすり抜けながら3つの区域を解放してください。

『ナイトストライカー』に着想を得た、独自のゲーム、絵、音楽です。

## 必要な環境

| 項目 | 内容 |
| --- | --- |
| 本体 | MSX turbo R。Panasonic FS-A1ST / FS-A1GTを想定 |
| グラフィックス | V9990カートリッジ、VRAM 512 KiB。GFX9000互換のI/Oポートを使用 |
| ゲームROM | 512 KiB / 524,288バイト、ASCII8マッパー対応カートリッジまたはROMローダー |
| 接続 | ゲームROMとV9990は別カートリッジ。両方を接続できるスロット構成 |
| 映像 | **V9990側の映像出力**を表示できるモニター。MSX本体の映像出力とは別 |
| 音源 | 本体内蔵MSX-MUSICとPSG。OPL4は不要 |
| 操作 | キーボード、またはジョイスティックポート1の2ボタンコントローラー |

描画はV9990 B1モード、256×212ピクセル、専用16色パレット、ダブルバッファーを使用します。前進する背景は画面中央の256×180ピクセルに表示します。実機での動作確認は未実施です。

最終v1.2 ROMで各区域の64フレームを連続測定し、3区域とも29.96更新/秒を確認しました。背景展開時間は都市4.906秒、工業区画4.039秒、中枢3.705秒でした。区域切り替え時の背景展開中は進行と音が一時停止します。起動時にも最初の区域を展開するため、画面が出るまで数秒お待ちください。

## Windowsで起動

このフォルダーの`launch-game.ps1`をPowerShellから実行します。

```powershell
& '.\outputs\launch-game.ps1'
```

`outputs`フォルダーを開いている場合は`& '.\launch-game.ps1'`で起動できます。同じフォルダーの`NEON_REVENANT-v1.2.rom`を起動します。タイトル画面でSpaceまたはトリガー1を押してください。ランチャーは起動後にGFX9000への映像切り替えを予約します。背景の展開が完了するまで待ってください。

ランチャーは、このPCの既存のワークスペース版openMSXを優先し、なければインストール済みopenMSXを探します。実行ファイルと機種を指定する場合：

```powershell
& '.\outputs\launch-game.ps1' -OpenMsxPath 'C:\Program Files\openMSX\openmsx.exe' -Machine FS-A1ST
```

`FS-A1GT`または完全な機種名`Panasonic_FS-A1ST`も指定できます。機種定義とシステムROMは既存openMSXの`share`を参照します。このゲームの配布物にBIOSは含みません。今回の起動用データは`work\play-profile`に保存し、環境変数は起動する子プロセスだけに設定します。

別のエミュレーターでは、turbo R機種、V9990 / GFX9000拡張、ROMマッパーASCII8を選び、V9990側の映像を表示してください。

openMSXを直接設定する場合は、機種をMSX turbo R、**Cart 1をV9990 / GFX9000、Cart 2を`NEON_REVENANT-v1.2.rom`（ASCII8）**にします。F10でコンソールを開き、次を入力してV9990側の映像を表示してください。

```tcl
set videosource GFX9000
```

F10でコンソールを閉じます。システムROMは利用者が用意した既存のものを使用してください。

## 操作

| 動作 | キーボード | ジョイスティック1 |
| --- | --- | --- |
| 移動・照準移動 | カーソルキー | 十字方向 |
| ショット・ゲーム開始 | Space | トリガー1 |
| NOVAボム | X | トリガー2 |
| ポーズ・再開 | Esc | キーボードのEsc |
| ゲームオーバー後の再挑戦 | Space | トリガー1 |
| クリア後の再出撃 | Space | トリガー1 |

ショットは押し続けると連射します。ボムは1回押すごとに1発使用します。ゲームオーバー／クリア直後の短い待ち時間が終わってから再挑戦できます。

## 遊び方

- 自機の移動に連動して、前方の照準枠も動きます。敵を枠に捉えて撃ってください。敵を捉えると枠の中心が明るくなります。
- 敵弾と、手前まで接近した敵機を避けて進みます。自機は上下にも移動できます。
- シールドは6、ボムは3で開始します。シールドが0になるとゲームオーバーです。
- NOVAボムは画面内の敵と敵弾を一掃し、ボスにもダメージを与えます。ボスへのとどめはショットで刺してください。
- 敵を短い間隔で倒すとCHAIN（画面左のX表示）が増え、撃破得点が上がります。最大CHAINは9。被弾や時間経過で途切れます。
- 敵が落とす回復アイテムに触れるとシールドが1回復し、50点を獲得します。シールド上限は6です。
- 区域を突破すると次の区域へ進みます。シールドは2回復して上限6、ボムは1補充して上限3になります。
- 3区域目のボスを倒すとクリア。残りシールドとボムが得点になります。

画面上部はSCORE、HI、SECTOR。下部はSH（シールド）、BOMB、演出用のSPD表示です。通常時の細いバーは区域の進行度、ボス戦ではボスの残り耐久力を示します。ハイスコアは起動中に保持します。

## 3つの区域

| 区域 | 舞台 | ボス |
| --- | --- | --- |
| 01 CHROME DISTRICT | ネオンの市街地 | WARDEN / INTERCEPTOR |
| 02 SKYWAY ASSAULT | 夜空へ伸びる高架道路 | RAZOR / SIEGE CARRIER |

## ソースからビルド

作業フォルダーの`src`がゲーム本体、`tools`が画像生成・ビルド・検証ツール、`assets`が生成された画像データ、`outputs`が配布物です。ビルドにはPythonとPillow、NumPy、SDCC、Pasmoを使います。PillowとNumPyはPC側の素材生成・検証用で、ゲーム実行時には不要です。配布ZIPのルートで`python -m pip install -r requirements.txt`を実行するとPython用の依存パッケージを導入できます。

検証に使用したSDCCは、MSXgl公式GitHubに同梱されたWindows版4.6.0 #16555です。取得スクリプトを実行すると`work\toolchain\sdcc`へ配置します。グローバルインストールは行いません。取得元を固定した再取得スクリプトがあります。

```powershell
# 作業フォルダーのルートで実行
python tools/download_sdcc.py
python tools/build.py
```

取得元は[MSXgl公式リポジトリ](https://github.com/aoineko-fr/MSXgl)、コミット`ab4b26feda36189e677aa23b56acfdc3218f7953`です。各ファイルはGit blob SHA-1で照合し、SHA-256とURLを`work\toolchain\sdcc\PROVENANCE.json`へ記録します。Windowsでプリプロセッサーを実行できるよう、元の`bin\cc1`を同じ内容の`bin\cc1.exe`としても配置します。

Pasmoは環境変数`PASMO`で指定した実行ファイル、またはPATH上の`pasmo`を使用します。別の場所にある場合は、現在のPowerShellで指定してからビルドしてください。

```powershell
$env:PASMO = 'D:\Tools\Pasmo\pasmo.exe'
python tools/build.py
```

必要なら環境変数`SDCC`で`sdcc.exe`も指定できます。ビルドはスプライトと3D背景の生成、背景のLZSS圧縮、Z80コードのコンパイルとリンク、ブートコードのアセンブル、ROMの組み立てを実行し、`outputs\NEON_REVENANT-v1.2.rom`と`outputs\build-manifest.json`を更新します。ROMは512 KiB固定です。この公開リポジトリではV9990 v1.2とTurbo R v1.0を配布します。

## 検証

背景生成では、3区域すべてについてカメラ位置0と1周後の描画が完全一致すること、16フレームのGIFを読み戻すと元の画像と一致することを検証しています。建物の固定位置が手前へ移動すると画面上の位置と大きさが変わることも数値で確認しています。これは生成素材の検証であり、実機動作の代わりにはなりません。

openMSX 21.0 / Panasonic FS-A1ST / GFX9000、Cart.2のASCII8 ROMで、起動・R800 DRAM動作・移動4方向・連射・ボム・ポーズ・再開・被弾・再挑戦・全3区域のボス登場/撃破/遷移・最終クリアを確認しました。各区域の背景368,640バイトと共通素材81,920バイトはVRAM読み戻しで全バイト一致し、背景展開後のMSX-MUSIC更新も確認しました。実行動画は各区域64フレームを撮影し、保存したGIFの全フレームが撮影画像と一致することを確認しています。

結果の保存先は`verification-v1.2.json`と`world-verification-v1.2.json`、エミュレーターが実行した画面・動画は`v1.2`フォルダーです。命中、被弾、ボス/区域遷移、動画撮影の開始状態はRAM設定を使って再現しました。通常操作だけで全編を通してクリアする試験ではありません。`visual-scope-review-v1.2.json`では、v1.1からのゲーム進行・戦闘・操作・音源・描画エンジンのソースと、全152件の素材配置座標が同一であることを確認しています。スプライト画像とパレットは今回の変更対象です。実機での動作確認は未実施です。

ROMは524,288バイト固定です。最終ビルドの配置領域は`build-manifest.json`の`allocated_bytes`、各区域の圧縮サイズと配置位置は`worlds`を参照してください。残りは0xFFで埋めます。スプライト・文字・UI素材は81,920バイト、各区域は展開すると368,640バイトで、プレイする区域の16フレームだけをVRAMへ常駐させます。

同梱の`msx3-concept.png`と`msx3-concept-prompt.txt`がある場合、これらはImageGenで作成した画づくりの参考画像と生成指示です。**ゲーム画面ではありません。** ROM用の16色素材は生成ツールで別途作成しています。実際の表示は`v1.2`フォルダーのネイティブ撮影画像・動画で確認してください。

配布ZIPは`NEON_REVENANT-v1.2-complete.zip`、ハッシュ一覧は`SHA256SUMS-v1.2.txt`です。
